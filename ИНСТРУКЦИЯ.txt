PRESSTESTER v1.3

1. Распакуй ZIP.
2. В репозитории Presstester замени старые файлы новыми, в том числе .github/workflows/build-apk.yml.
3. Commit changes.
4. GitHub Actions -> Build Presstester APK -> открыть успешную сборку.
5. Скачать артефакт Presstester, распаковать, установить Presstester.apk.

ВНИМАНИЕ: это исходники, не готовый APK.
Чтобы заменить синтетический голос на человеческий, замени app/src/main/assets/six-seven.mp3.
